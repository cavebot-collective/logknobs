# logknobs
Logknobs is a visual configurator for git log --pretty/--format templates. Insert, reorder and restyle parts, preview one commit or a --graph history in real terminal themes, and export presets or git config aliases. The preview is a simulator verified byte-for-byte against real git 2.43, and pixel-compared in the UI. Browser + Electron.

## Quick start

    cd app
    npm ci
    npm run build                  # -> app/dist/index.html, one self-contained file
    # open app/dist/index.html in a browser, or the desktop build (adds real-git mode):
    GITLOG_REPO=/path/to/repo npx electron electron/main.js

## Layout

| path | what |
|---|---|
| `app/` | the configurator: `src/app.html`, `src/quoting.mjs`, Electron host, brand, gates (`tests/`) |
| `probe/sim/` | the simulator: template engine, revision walk, graph.c port, multi-commit view |
| `probe/scripts/` | fixture builders, corpus generators, registry builder, spelling lint |
| `probe/evidence/` | recorded git output (golden corpora) and the generated registry; data, never rewritten in place |
| `research/` | preset and terminal-theme sources, with provenance and hashes |
| `docs/spec/` | the specification, every version |
| `scripts/setup-work.sh` | builds the sample repositories into `.work/` and checks their commit ids |

## Verification

    cd app && npm run verify       # every gate, each under a timeout

Requires git **2.43.0** exactly (the evidence is bound to it; Oracle A halts on
any other version), Python 3, Node 22, and Xvfb on Linux.

| gate | asserts |
|---|---|
| Oracle A | simulator output == git's bytes: 1724 template vectors, color grammar, `--graph` (incl. 192 on unseen random repos), decorations, tokenizer, presets |
| registry | T1–T7, T9, T13, T15 over the generated registry; regenerated byte-identical |
| quoting | bash commands executed; MSVCRT layer round-trips (Linux half) |
| T8 v2, T10–T14 | controls and applicability, knobs, undo/redo, drag/drop, presets and config export against real git, American spelling |
| T16 | no identifying label is clipped, at the minimum and maximum of every resizable region, both layouts |
| T17 | every inventoried action works mouse-only and keyboard-only (keyboard paths reached by Tab), both layouts |
| Oracle B | preview pixels == real git's bytes painted, five terminal themes |
| real git | the desktop host's git mode agrees, and refuses unlisted flags |
| windows-quoting | cmd (prompt and .bat), PowerShell 7, Windows PowerShell 5.1: generated commands == git invoked directly |

CI runs `verify` on ubuntu-24.04 and `windows-quoting` on windows-latest; every
job and step has a timeout.
